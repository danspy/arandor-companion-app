# Installed app (PWA)

Arandor can be installed on a phone or tablet like an app. It then opens full screen, without
the browser's address bar.

## Installing

| Device | Steps |
|---|---|
| iPhone / iPad (Safari) | Open arandor.app → *Share* → *Add to Home Screen* |
| Android (Chrome) | Open arandor.app → menu ⋮ → *Install app* (or *Add to Home screen*) |
| Desktop (Chrome, Edge) | Install icon at the right of the address bar |

A long press on the app icon offers shortcuts to Diary, Characters and Map (Android).

## What is different in the installed app

On screens up to 1024 px wide, the installed app replaces the top navigation:

- **Menu button** (bottom right): all pages, your profile, the user admin (admins) and
  log out.
- **Quick access bar** (bottom left, when logged in): up to **4 favourite pages**. Choose and
  order them in **Profile → Favourite pages** (drag to reorder). Pages your role can't use are
  left out.
- **Dice button** sits above the menu button. Opening the menu closes the dice panel.
- A dark gradient behind the phone's status bar keeps the clock and battery readable.

The app needs a connection: there is no offline mode (no service worker).

## Icons and splash screens

| Source | Generated by | Output |
|---|---|---|
| `public/icons/icon.svg` | `npm run generate-icons` | `public/icons/icon-*.png`, `apple-touch-icon*.png`, `public/favicon.png` |
| `public/icons/icon-maskable.svg` (full-bleed, keep the important part in the centre 80 %) | `npm run generate-icons` | `public/icons/icon-maskable-*.png` (Android) |
| icon + background colour | `npm run generate-splash` | `public/splash/apple-splash-*.png` (iOS start screens; the app uses the `-dark` ones) |
| running app | `npm run generate-screenshots` | `public/screenshots/` (install dialog on Android) |

`npm run generate-all-assets` runs all three. After changing icons, reinstall the app on a test
device; phones cache icons aggressively.

The manifest is `public/manifest.webmanifest`; the iOS tags are in `src/layouts/Layout.astro`.

## For developers

- Installed-app styles apply under `@media (display-mode: standalone) and (max-width: 1024px)`.
  The `.pwa-hide-nav` / `.pwa-hide-footer` classes hide the normal navigation there.
- Safe areas (notch, home indicator) come from `env(safe-area-inset-*)`, exposed as
  `--safe-top` and friends in `src/styles/global.css`. The main area gets bottom padding so the
  floating buttons never cover content.
- Components: `src/components/PWAFloatingMenu.astro`, `src/components/PWAQuickAccess.astro`;
  the dice button stacks above the menu via `--dice-fab-bottom` in `DiceFab.astro`.
- To test the installed layout in a desktop browser, use the device toolbar and emulate
  `display-mode: standalone`, or install the app on a phone and open dev.arandor.app.
